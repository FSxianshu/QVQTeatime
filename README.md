# QVQTeatime
如你所见，这是一个备份存放歌声合成向工程文件的地址。

# About

请在原曲作者规定的范围内使用:

**允许:**

1. 随压缩包附带的伴奏仅供参考, 如有需求, 请从官方频道下载.
2. 使用本工程无需授权, 注明作者 (例: SVP 赋水仙术) 即可; 此外, 您可以随意转换工程格式.
3. 有参工程均可用于套参并发布视频, 音频等, 但请勿二次配布.
4. 可以使用该工程进行约稿.
5. 允许将该工程用于 AI 换声模型项目 (如 RVC 类), 有授权的 AI 换声软件 (如 Vocoflex 类), 人力 Vocaloid 以及鬼畜视频制作, 但本人不对由此产生的任何问题负责.

**禁止:**

1. 禁止倒卖, 二次配布该工程, 或发表自作发言.
2. 禁止在使用该工程时超出原曲作者规定的使用范围.
3. 禁止使用该工程文件进行非法的二次创作.
